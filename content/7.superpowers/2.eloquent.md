## Introduction

The Eloquent superpower lets the agent evaluate PHP code in the context of your Laravel application using Tinker. The agent can call any Eloquent model, scope, query builder method, or facade you've defined — anything that works in `php artisan tinker` works here.

Ask *"how many orders did we ship last week?"* and the agent writes the query, runs it, and answers.

It's disabled by default.

## Enabling Eloquent Access

```env
LARACLAW_TINKER_ENABLED=true
```

You'll also need `laravel/tinker` installed:

```bash
composer require laravel/tinker
```

## Running Queries

The tool accepts a single parameter:

| Parameter | Required | Description |
|---|---|---|
| `code` | Yes | PHP code to evaluate |

The code is passed to `php artisan tinker --execute`, and the output is returned as JSON containing `exit_code` and `output`.

## Working With Your Models

The agent has access to everything in your `app/Models` directory and uses it the way you would in a Tinker session:

```php
App\Models\Order::where('shipped_at', '>=', now()->subWeek())->count();
```

```php
App\Models\User::with('subscription')
    ->where('subscription.cancelled_at', null)
    ->count();
```

For the agent to use your models effectively, model and column names should be self-describing. A `User` model with `last_login_at` is easier for the agent to reason about than one with `lla` or `t3`.

## Output Limits

Output is capped at **100 KB**. Beyond that the response is truncated with a marker.

## Security Considerations

> [!WARNING]
> Eloquent access is full PHP execution inside your application. The agent can read **and write** any model. There is no read-only mode.

- **Wrap write operations in custom tools** that declare `requiresConfirmation`. The Eloquent superpower itself does not prompt before running code.
- **Set `LARACLAW_LOG_AGENT_REQUESTS=true`** to log every prompt and response.
- **Be deliberate about who can message the bot.** With Eloquent access enabled, every trusted sender effectively has database write permissions.

For narrower access — for example, *"the agent may only run queries against the `orders` table"* — build a [custom tool](/tools/adding-custom-tools) that exposes exactly that, and leave the Eloquent superpower disabled.
